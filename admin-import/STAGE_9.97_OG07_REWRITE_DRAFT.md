## 8. Detector: multiplier / performance rule (general; no resource is named)
Flags a multiplier attached to result language in one sentence. Forms: `2x`, `2×`, `2-3x`, `2–3x`, `twice`, `thrice`, `N times` (digits or spelled, including "one and a half"), `-fold`, and `double/triple/quadruple` only when followed by "the/as/your/their/its/that". Result language: effective, efficient, faster, quicker, speed, productive, results, progress, improve, better, outcome, output, savings, gains, success/succeed, likely, follow-through, performance, achieve, reliable, stronger, longer, boost, increase, enhance, growth, returns, impact. Two shapes: multiplier then result word ("2x more effective", "twice as effective", "three times faster") and result word then multiplier ("increases output by 2x", "achieves 3 times the progress"). Quiet for questions, "for example", negations ("does not guarantee a 2x improvement"), blanks, "if you / whether", and a sentence that opens with an instruction (choose, select, write, record, compare, review, check, list, rank…). A bare "x" (a member's "2 x batteries", "3x4 metres"), "twice a week", "two times this week" and "double-glazed" do not flag. New category value `performance` (units `multiplier` / `comparative`); every hit is `C_NEEDS_SOURCE`. *(A first version read "double" in "double-glazed" as a multiplier and flagged live OG-15; the rule was tightened and a regression test added; no exemption was made.)*

## 9. Detector: comparative-performance rule
Flags an unsupported outperformance statement set against a population: (1) "more/greater/better/faster … progress|results|success|gains|improvement|output|productivity|impact **than** most / many / the average / typical / nearly all / the majority of / other"; (2) "faster / quicker / better / stronger / more effective|efficient|productive|successful|reliable|powerful … than the average / most / typical + (people|households|homes|families|approaches|methods|plans|options|systems|programmes)"; (3) "achieves / accomplishes / gets / makes / does / sees / gains more|better … than most / the average / typical". Overlapping matches are one statement. It needs both comparative form and performance context, so comparison questions and member prompts ("Which option is better for you?", "Compare the three plans", "Write down what worked better", "Pick the plan that gives you better results than last month") stay quiet.
